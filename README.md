## 🚀 Overview
**Phantom The System** is an advanced, centralized cybersecurity operations framework designed and built from scratch inside Termux. It acts as an all-in-one command center to manage security testing tools, vulnerability scanners, and port analysis utilities with an integrated AI-like smart terminal assistant (**PHANTOM CO-PILOT**).

---

## 🛠️ Framework Modules & Tools
1. **Phantom Scanner (v2.0):** 
   - Automated vulnerability detection tool.
   - Detects **Reflected XSS** vulnerabilities in HTTP GET endpoints.
   - Detects **Command Injection** vulnerabilities in server ping endpoints.
2. **Phantom Ports (v1.0):** 
   - Fast TCP port scanner designed to check critical target ports (e.g., ports 21, 22, 80, 443, 3306, 5000, 8080).
3. **Phantom Lab:** 
   - Local vulnerable Flask web server environment built for safe penetration testing and payload verification.
4. **PHANTOM CO-PILOT:** 
   - Natural language command assistant and smart terminal interpreter for seamless tool execution.
